Perguntas frequentes

Preciso saber programar para usar o ZapFlow?

Não. O construtor visual de arrasta e solta foi feito para times de marketing, vendas e suporte montarem fluxos completos sem escrever código.
O ZapFlow funciona com a API oficial do WhatsApp Business?

Sim. Toda a operação roda sobre a API oficial, respeitando os limites e as políticas da plataforma para manter seu número seguro.
Posso testar antes de contratar um plano?

Sim, todos os planos incluem 7 dias grátis para testar o construtor de fluxos e o assistente de IA antes de decidir.
Como funciona o robô de atendimento com IA?

Você treina o assistente com as informações do seu negócio. Ele responde dúvidas, qualifica o lead e escala para um humano quando necessário.
Dá para integrar com meu CRM ou sistema atual?

Sim. O plano Pro inclui API, webhooks e uma central de integrações prontas para as ferramentas mais usadas.
Existe limite de mensagens ou contatos?

O plano Starter tem um limite mensal de conversas. O plano Pro é ilimitado, respeitando as políticas da Meta para envio.
Preciso trocar o meu número de WhatsApp?

Não. Migramos o número que você já usa para a API oficial, sem perder o histórico de contatos.
